# chat-bot-SibCoding
Чат-бот для бронирования пространства «Сибкодинг» в ИКИТ СФУ. 

ИС представляет собой чат-бот для бронирования пространства «Сибкодинг» в ИКИТ СФУ. Она предназначена для студентов и сотрудников СФУ и позволяет быстро проверить свободные слоты, оформить бронь и получить подтверждение. Система снижает нагрузку на администратора и исключает конфликты при бронировании.

Состав команды: 
- Войцехович Елена: тестировщик
- Зарецкая Варвара: аналитик
- Кузнецова Карина: руководитель
- Шпильберг Натан: разработчик, архитектор
