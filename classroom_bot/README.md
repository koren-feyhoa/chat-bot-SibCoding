# Telegram Classroom Booking Bot

## Описание

Этот проект — Telegram-бот для бронирования СибКодинга в ИКИТ СФУ с интеграцией Google Calendar. Поддерживаются роли пользователя и администратора, автоматическая проверка занятости времени, просмотр и отмена заявок, а также удобное меню для взаимодействия.

---

## Функционал
- **Пользователь:**
  - Бронирование аудитории (дата, время, описание)
  - Проверка занятости слотов
  - Получение уведомлений о статусе заявки
- **Администратор:**
  - Просмотр, одобрение и отклонение заявок
  - Отмена бронирований через меню
  - Управление пользователями (через CSV)

---

## Установка и запуск

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   git clone <repo_url>
   cd classroom_bot
   ```
2. **Создайте и активируйте виртуальное окружение (рекомендуется):**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Создайте файл `.env` на основе `.env.example` и заполните переменные:**
   - `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота
   - `GOOGLE_CALENDAR_ID` — ID календаря Google
   - `ADMIN_USER_ID` — Telegram user ID администратора
5. **Добавьте файл `credentials.json` Google API в папку проекта.**
6. **(Опционально) Добавьте файл `admin_users.csv` для расширенного списка админов.**
7. **Запустите бота:**
   ```bash
   python bot.py
   ```

---

## Переменные окружения
- `TELEGRAM_BOT_TOKEN` — токен Telegram-бота
- `GOOGLE_CALENDAR_ID` — ID календаря Google
- `ADMIN_USER_ID` — Telegram ID основного администратора

---

## Структура проекта
- `bot.py` — основной файл бота
- `bot_utils.py` — вспомогательные функции (проверка времени, форматирование)
- `admin_cancel_callback.py` — логика отмены бронирования админом
- `pending_bookings.json` — локальное хранилище заявок
- `admin_users.csv` — список Telegram ID админов
- `requirements.txt` — список зависимостей
- `.env` — переменные окружения

## FAQ
**Q: Как добавить нового администратора?**
A: Добавьте его Telegram ID в файл `admin_users.csv` (по одному в строке).

**Q: Как получить Google Calendar ID?**
A: В настройках Google Calendar, раздел "Интеграция календаря".

**Q: Не работает интеграция с Google API?**
A: Проверьте наличие и корректность `credentials.json` и переменных окружения.

**Q: Как сбросить все заявки?**
A: Удалите файл `pending_bookings.json` (или очистите его содержимое).
